🚀 CCRAFT SPACE API

اربط موقعك أو تطبيقك أو الروبوت الخاص بك بمحتوى CCRAFT SPACE — السكربتات ومحتوى المجتمع، عبر مفتاح API خاص بك.

Base URL https://ghgh62131r.pythonanywhere.com
ℹ️
هذا الـ API مبني على خادم Flask خاص بالمنصة فوق قاعدة بيانات Supabase. يجب إرسال المفتاح في ترويسة X-API-Key مع كل طلب. المفاتيح مجانية، ولكل مفتاح حد أقصى قدره 60 طلبًا في الدقيقة.
🔑 إنشاء مفتاح API الخاص بك

يلزم تسجيل الدخول إلى الموقع أولًا. يُعرض المفتاح الكامل مرة واحدة فقط — احتفظ به في مكان آمن.

✅ تم إنشاء المفتاح بنجاح
⚠️ سيظهر هذا المفتاح مرة واحدة فقط — انسخه واحفظه الآن، إذ لن نتمكن من عرضه لك مرة أخرى.
📂 مفاتيحي

لا يُحتفظ بالمفتاح الكامل لدينا بعد إنشائه، بل بصيغة مشفّرة فقط. لذا في حال فقدانه، لن يكون بالإمكان استرجاعه — والحل هو إلغاء المفتاح القديم وإنشاء مفتاح جديد بدلًا منه.

📡 الواجهات البرمجية العامة
🧭 كيفية الحصول على سكربت بكوده الكامل
هناك طريقتان، اختر الأنسب لحالتك:
الطريقةالوصف
السريعةأضِف ?include_code=true إلى واجهة القائمة — يعيد الكود مع كل سكربت ضمن الطلب نفسه
الدقيقةاجلب القائمة أولًا (دون كود)، ثم اطلب أي سكربت بعينه كاملًا باستخدام معرّفه
 
// الطريقة السريعة — الكود ضمن القائمة مباشرة
const res = await fetch('https://ghgh62131r.pythonanywhere.com/api/v1/scripts?include_code=true&limit=10', {
  headers: { 'X-API-Key': 'ccsk_...' }
});
const { scripts } = await res.json();
console.log(scripts[0].code); // الكود موجود مباشرة
// الطريقة الدقيقة — خطوتان
const list = await fetch('https://ghgh62131r.pythonanywhere.com/api/v1/scripts', {
  headers: { 'X-API-Key': 'ccsk_...' }
}).then(r => r.json());

const id = list.scripts[0].id;
const full = await fetch(`https://ghgh62131r.pythonanywhere.com/api/v1/scripts/${id}`, {
  headers: { 'X-API-Key': 'ccsk_...' }
}).then(r => r.json());

console.log(full.script.code);
GET /api/v1/scripts/{id} 🔑 يتطلب X-API-Key
جلب سكربت واحد كاملًا بكوده — يُستخدم بعد الحصول على المعرّف من واجهة القائمة أدناه.
// JavaScript
const res = await fetch('https://ghgh62131r.pythonanywhere.com/api/v1/scripts/SCRIPT_ID', {
  headers: { 'X-API-Key': 'ccsk_...' }
});
const { script } = await res.json();
console.log(script.code); // الكود الكامل هنا
GET /api/v1/scripts 🔑 يتطلب X-API-Key
جلب قائمة السكربتات (الأحدث أولًا)، مع إمكانية الفلترة بالقسم وتحديد عدد النتائج.
البارامترالنوعالوصف
limitاختياريعدد النتائج (الافتراضي 20)
categoryاختياريgame / admin / ai
include_codeاختياريtrue لإعادة الكود مع كل سكربت ضمن الطلب نفسه
 
// JavaScript
const res = await fetch('https://ghgh62131r.pythonanywhere.com/api/v1/scripts?limit=10', {
  headers: { 'X-API-Key': 'ccsk_...' }
});
const { scripts } = await res.json();
console.log(scripts);
# Python
import requests

res = requests.get(
    "https://ghgh62131r.pythonanywhere.com/api/v1/scripts",
    headers={"X-API-Key": "ccsk_..."},
    params={"limit": 10}
)
scripts = res.json()["scripts"]
