🚀 CCRAFT SPACE API

اربط موقعك أو تطبيقك أو بوتك بمحتوى CCRAFT SPACE — سكربتات ومحتوى المجتمع، عن طريق مفتاح API خاص بيك.

Base URL https://ghgh62131r.pythonanywhere.com
ℹ️
الـ API الجديد مبني على سيرفر Flask خاص بينا فوق قاعدة بيانات Supabase — كل طلب لازم يبعت مفتاحك في هيدر X-API-Key. المفاتيح مجانية، وكل مفتاح ليه حد أقصى 60 طلب في الدقيقة.
🔑 اعمل مفتاح API بتاعك

لازم تكون مسجل دخول على الموقع الأول. المفتاح بيتعرض مرة واحدة بس — احفظه في مكان آمن.

✅ اتعمل المفتاح بنجاح
⚠️ ده هيظهر مرة واحدة بس — انسخه واحفظه دلوقتي، مش هنقدر نوريهولك تاني.
📡 الـ Endpoints العامة
GET /api/v1/scripts 🔑 محتاج X-API-Key
جلب قائمة السكربتات (أحدثها أولاً). تقدر تفلتر بالقسم وتحدد عدد النتائج.
البارامترالنوعالوصف
limitاختياريعدد النتائج (افتراضي 20)
categoryاختياريgame / admin / ai
 
// JavaScript
const res = await fetch('https://ghgh62131r.pythonanywhere.com/api/v1/scripts?limit=10', {
  headers: { 'X-API-Key': 'ccsk_...' }
});
const { scripts } = await res.json();
console.log(scripts);
# Python
import requests

res = requests.get(
    "https://ghgh62131r.pythonanywhere.com/api/v1/scripts",
    headers={"X-API-Key": "ccsk_..."},
    params={"limit": 10}
)
scripts = res.json()["scripts"]
